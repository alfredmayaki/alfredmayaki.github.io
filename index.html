🛸 This is a frontend Python 3, JavaScript and HTML5 web application that was created by simply using an index.html file in GitHub and developed using the Visual Studio IDE and further developed at a later date using the Microsoft VS Insiders 2026 IDE. It is deployed from GitHub to a student-licensed app on Heroku and then through a wrangler deploy command using Cloudflare, the main search protocol on the homepage calls Claude Code 3.5 Haiku for the chatbot feature. This is achieved via an index.js file.

🌍 The application consists of a personal profile of mine which offers multilingual support for its readership ~ in English as well as in 14 other languages. More languages may become available at a later date.

💜 All outbound weblinks that are displayed on this website have been screened for safety. Please ensure precaution is taken when clicking links, as from time to time, embedded links may have been written manually and may contain errors.
