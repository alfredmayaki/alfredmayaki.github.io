Welcome to my Personal Website

Labour Economist, Public Policy Researcher, and Human Resource Business Partner

The Open University & Royal Economic Society

🛸 This app uses a backend tech stack of Python 3, FireBase + Node.js, and a frontend stack of JavaScript CSS, and HTML5 to generate a web application created in January 2026 by simply using an index.html file in GitHub that was developed in the Visual Studio IDE and further developed in the Microsoft VS Insiders 2026 IDE. It is deployed from GitHub to a student-licensed app on Heroku and then through a wrangler deploy command using Cloudflare, the main search protocol on the homepage calls Claude Code 4.5 Opus for the chatbot feature. This is achieved via an index.js file.

🌍 The application consists of a personal profile of mine which offers multilingual support to its readership ~ in English as well as in 14 other languages. More languages may become available at a later date.

💜 All outbound weblinks that are displayed on this website have been screened for safety. Please ensure precaution is taken when clicking links, as from time to time, embedded links may have been written manually and may contain errors.

⚪ This main branch of this repo is a public code repository, which will be supported throughout the entirety of its SDLC lifecycle by me personally and by my Discord comrades from The Open University. Forks and other requests can be made on an as-and-when basis, as is usually the case.
